# 문양검색 0.18.3 — 자동 가중치 설치형 (Windows / Linux)

비전문가가 이미지와 정답 데이터를 추가하고, 기존 가중치를 추가 학습한 뒤 비교·선택·저장하는 프로그램입니다. 웹이나 브라우저가 아닌 PySide6 데스크톱 화면입니다.

## 한 화면에서 사용하기

1. **데이터 폴더 선택 / ZIP·CSV 선택**: 이미지와 정답이 있는 데이터를 추가합니다. 이미 등록했다면 목록에서 고릅니다.
2. **기준 가중치 → 학습 시작**: 처음에는 기본 가중치가 선택됩니다. 이전에 적용한 가중치가 있으면 그 가중치를 기본으로 사용합니다. 필요하면 다른 보관 가중치도 선택할 수 있습니다. CPU 또는 NVIDIA GPU 0을 선택합니다.
3. **성능 비교**: 같은 평가 이미지에 대한 기존·새 가중치의 F1@5, 차이(%p), 어느 쪽이 높은지를 표시합니다. 학습 기록을 바꿔 이전 결과도 확인할 수 있습니다.
4. **가중치 선택**: 비교표에서 기존 또는 새 가중치 행을 누릅니다. **선택 가중치 적용**을 누르고 확인하면 다음 학습의 기본값으로 저장됩니다. 자동으로 새 가중치로 바꾸지 않습니다.
5. **선택 가중치 다른 이름으로 저장…**: 폴더와 ZIP 이름을 지정하면 선택한 가중치와 필요한 원본 백본·설정을 함께 내보냅니다. 적용하지 않은 가중치도 저장할 수 있으며, 저장만으로 현재 적용 가중치가 바뀌지 않습니다.

성능이 떨어지면 기존 가중치를 그대로 사용할 수 있습니다. 같은 수치일 때도 사용자가 선택합니다. 적용/저장은 원본 가중치와 등록 데이터를 삭제하지 않습니다. 같은 이름의 ZIP 교체는 별도로 확인합니다. 내보낸 ZIP은 모델에 따라 수 GB 이상일 수 있으므로 충분한 로컬 공간이 필요합니다.

## 0.18.3 — 우클릭으로 저장·삭제하기

화면이나 탭을 추가하지 않았습니다. 목록을 펼친 뒤 원하는 항목에서 **마우스 오른쪽 버튼**을 누르면 **다른 이름으로 저장… / 삭제…** 메뉴가 나옵니다. 목록을 펼치지 않고 선택 칸에서 우클릭하면 현재 선택 항목을 처리합니다.

우클릭해도 **펼친 목록은 그대로 유지되고 그 위에 메뉴가 뜹니다.** Esc를 한 번 누르면 메뉴만 닫혀 목록에서 계속 선택할 수 있습니다. 저장·삭제 명령을 선택했을 때만 목록을 닫고 해당 창을 엽니다. 이 동작은 등록 데이터·기준 가중치·학습 결과 목록에 공통으로 적용됩니다.

| 우클릭 위치 | 다른 이름으로 저장 | 삭제 대상 |
| --- | --- | --- |
| 1. 등록된 데이터 목록 | 해당 묶음의 이미지·labels.csv·분할·원본 ZIP 메타데이터를 ZIP으로 저장 | 해당 데이터 묶음을 학습 목록에서 제외 |
| 2. 기준 가중치 목록 | 해당 가중치와 필요한 백본·설정을 ZIP으로 저장 | 해당 가중치를 사용 목록에서 제외 |
| 3. 학습 결과 목록 | 그 학습에서 만들어진 **새 가중치**를 ZIP으로 저장 | 해당 **학습 기록을 목록에서 삭제**. 가중치·원본 데이터·내부 결과와 로그는 보존 |
| 3. 성능 비교표의 기존/새 가중치 행 | 우클릭한 행의 가중치를 ZIP으로 저장 | 우클릭한 행의 가중치만 대상 |

현재 선택된 다른 행이 아니라 **실제로 우클릭한 항목**을 처리합니다. 이름을 확인한 뒤 삭제를 승인하세요. 학습 결과 목록의 삭제와 가중치 삭제는 별개입니다. 가중치가 이미 삭제됐거나 현재 사용 중이어도 종료된 학습 기록은 목록에서 삭제할 수 있습니다. 실패·중단된 기록도 삭제할 수 있으며, 실행 중인 학습은 삭제할 수 없습니다. 저장할 가중치가 없는 기록에서는 '다른 이름으로 저장'만 비활성화됩니다. 삭제한 기록은 재실행 후에도 목록에 나타나지 않습니다.

### 안전하게 삭제하기

- 학습·파일 처리 중에는 삭제·저장을 막습니다.
- 현재 적용 중인 가중치는 삭제할 수 없습니다. 사용할 다른 가중치를 먼저 적용해야 합니다.
- 다른 가중치가 참조하는 원본 백본/기준 가중치도 삭제할 수 없습니다.
- **데이터 삭제는 등록 목록에서 제외하는 기능입니다.** 사용자 원본과 과거 학습에 쓰인 등록 사본을 보존하므로 즉시 저장 공간이 줄지는 않습니다.
- **학습 기록 삭제도 목록 정리입니다.** 내부 결과·로그·이력을 유지하므로 가중치나 데이터 용량을 줄이지 않습니다. 가중치를 지우려면 기준 가중치 목록에서 해당 가중치를 우클릭하세요.
- **가중치 삭제는 기존 보관 정책을 따릅니다.** 자동 정리가 켜져 있으면 설정된 유예기간이 지난 뒤 프로그램 실행 중에 참조 여부를 다시 검사하고 영구 삭제합니다. 꺼져 있으면 파일은 계속 보관됩니다. 이번 업데이트가 보관 정책을 새로 켜거나 변경하지는 않습니다.
- 삭제 확인 창에 현재 정책을 안내합니다. 이번 간단 화면에는 보관 기간 변경·복원 메뉴를 추가하지 않았습니다.
- 데이터 목록에서 지워도 이미 학습한 가중치에서 해당 정보가 지워지는 것은 아닙니다.
- '다른 이름으로 저장'은 복사 내보내기입니다. 기존 파일·현재 적용 가중치·분할은 변경하지 않습니다. 같은 파일명으로 저장할 때는 덮어쓰기를 확인합니다.
- 저장 위치는 별도의 로컬 폴더를 선택합니다. 프로그램 내부 데이터/모델 저장소와 NAS에는 내보내지 않습니다.

## 변경된 화면과 고정 설정

- 간편학습과 설정·관리 화면을 나누지 않습니다. 별도 탭·고급 설정·추론·보관함·저장 경로 설정 화면은 없습니다.
- 에폭 **10**, 배치 크기 **8**, 학습률 **0.0001**로 고정합니다. 사용자가 입력할 필요가 없습니다. 이 값이 모든 데이터의 최적 성능을 보장하지는 않습니다.
- 검증 데이터가 있으면 그 결과가 가장 좋은 에폭의 가중치를 저장합니다. 없으면 정해진 마지막 에폭을 저장합니다. 평가 데이터를 최고 에폭 선택에 사용하지 않습니다.
- 기존 데이터 분할·학습 엔진·지표 계산·가중치 자체는 바꾸지 않았습니다. 예전 저장 위치 설정과 보관 기간 정책도 그대로 유지됩니다.
- 데이터·가중치 저장과 삭제는 우클릭 메뉴에서 처리합니다. 저장 위치 변경·개별 이미지 추론의 서비스 내부 기능과 기록은 보존하지만 별도 화면은 노출하지 않습니다.
- 웹 서비스에 자동 배포하지 않습니다.

## 설치와 업데이트

Windows: Python 3.11 x64 설치 후 로컬 폴더에 압축을 풀고 **install-windows.bat → start-windows.bat** 순서로 실행합니다.
Linux: 로컬 폴더에서 **bash install-linux.sh → bash start-linux.sh** 순서로 실행합니다.

AUTO_WEIGHTS 패키지는 설치할 때 기존 배포 원본 가중치를 다운로드·검증·조립합니다. BOTH_MODELS 백업은 두 원본 모델을 포함합니다. 첫 설치에는 네트워크와 모델 저장 공간이 필요합니다. 이미 정상 설치된 모델은 다시 내려받지 않습니다.

업데이트는 프로그램을 종료하고 기존 실행 폴더에 새 코드 파일을 덮어씁니다. **workspace와 가상환경을 지우지 마세요.** 기존 데이터·추가 학습 가중치·적용 설정을 보존하며, 업데이트만을 위해 재학습할 필요는 없습니다.

## 데이터 준비

이미지 파일과 UTF-8 **labels.csv**가 필요합니다. 폴더나 ZIP을 고르거나 CSV를 직접 선택할 수 있습니다. CSV에 적힌 이미지 경로는 CSV 위치 기준입니다.

CSV 열: **id,image,labels,split,description**

- id: 표본을 구분하는 고유값.
- image: images/example.png처럼 상대 이미지 경로.
- labels: 프로그램의 22개 감성어 중 서로 다른 정답 5개를 세미콜론으로 구분.
- split: train(학습), dev(검증), eval(평가). 등록한 분할을 유지하며 자동으로 섞거나 새로 나누지 않습니다.
- description: 이미지 전용 모델에서는 비워도 됩니다. 5종 BERT 모델에는 원설명문이 필요합니다.

정답 없는 이미지 단독 추가나 화면에서 정답을 만들어 붙이는 기능은 없습니다. 학습 표본이 적어도 한 장은 필요합니다. 별도 평가 표본이 없으면 F1@5 대신 **평가 데이터 없음**으로 표시합니다. 한 장으로 학습하고 같은 이미지를 다시 확인한 결과는 일반화 성능이 아닙니다.

## 성능 비교 기준

F1@5는 이미지마다 예측한 감성어 5개와 정답 5개가 얼마나 일치하는지 집계합니다. 각 표본의 정답과 예측이 모두 5개일 때 **맞힌 정답 슬롯 수 / (평가 이미지 수 × 5)**입니다.

비교표는 선택한 학습 기록의 동일한 평가 이미지와 실제 학습 시작 가중치를 기준으로 합니다. 현재 적용 모델이나 다른 데이터에서 측정한 과거 수치를 대신 사용하지 않습니다. 평가 파일이 없거나 기준 결과가 없으면 비교할 수 없다고 표시합니다. 학습 성능을 평가 성능으로 대신 표시하지 않습니다.

화면에 표시되는 값은 사용자가 넣은 데이터의 실측값이며, 80%나 86%로 고정된 수치가 아닙니다. 기존 배포 이미지 모델의 원기록에는 평가 이미지의 학습 재사용이 포함되어 있어 독립 테스트 성능으로 해석하지 않습니다. 5종 BERT의 원기록 80%는 이미지+원설명문 조건입니다.

## 무엇을 학습하고 저장하는가

이미지 기본 모델은 기존 DINO A/B 분류 헤드를 이어서 학습합니다. DINO 특징 추출부·RBF 구성·앙상블 규칙은 유지합니다. 5종 BERT 모델 역시 기존 엔진의 추가 학습 규칙을 사용합니다. 이번 UI 변경은 전체 인코더 재학습 방식의 변경이 아닙니다.

선택한 가중치를 적용하면 그 모델 ID가 active.json에 남아 다음 실행과 다음 학습의 기본값이 됩니다. 추가 학습 결과는 별도 모델 버전으로 남습니다. 이전 원본을 덮어쓰지 않습니다. 분류 헤드 파일 하나만 외부에 복사하면 원본 의존성이 빠질 수 있으므로 **다른 이름으로 저장**을 사용하세요.

기본 데이터/가중치 위치는 workspace/datasets와 workspace/models이며 이전에 변경했다면 workspace/storage.json의 로컬 경로를 유지합니다. 실행 기록·설정·결과·표본별 예측은 workspace/runs에 남습니다. NAS·네트워크·심볼릭 링크 우회 저장은 허용하지 않습니다.

## 검증 범위

기존 Linux 컨테이너에서 실제 Qt 화면, 고정 설정의 소형 모델 추가 학습, 동일 평가 비교, 기존/신규 선택, 적용 지속성, 가중치 ZIP 내보내기·재로딩을 검증합니다. 기능 검증용 합성 데이터와 소형 모델의 수치는 연구 성능 주장이 아닙니다. Windows용 실행 파일을 포함하지만 실제 Windows에서 수행한 검사와 Linux 검사를 혼동하지 않습니다.

모델 형식과 원본 기록의 제약은 MODEL_FORMAT.md, 검증 이력은 VALIDATION.md를 참고하세요.

## 자동 가중치 설치

install-windows.bat 또는 install-linux.sh가 원본 가중치 조각 6개를 내려받고 순서·용량·SHA-256을 검증한 뒤 조립합니다. 이미 설치된 원본과 추가 학습 가중치는 덮어쓰지 않습니다. 설치가 끊기면 다시 같은 설치 파일을 실행하세요. 검증된 조각은 재사용합니다.

오프라인 설치가 필요하면 원본 weights.zip.part001~006을 실행 폴더의 weight_parts에 모두 넣고 설치합니다. weights_parts.json의 검증 정보를 바꾸지 마세요. 설치기가 받은 임시 조각은 정상 완료 후 정리하지만 사용자가 넣은 원본 조각은 삭제하지 않습니다.
