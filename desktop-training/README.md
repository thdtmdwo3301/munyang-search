# 문양검색 0.15.1 — 자동 가중치 설치형 (Windows / Linux)

## 학습 설정 표시

고급 설정에서 **에폭 · 배치 크기 · 학습률**을 사용합니다. 기본값은 에폭 10, 배치 크기 8, 학습률 0.0001입니다. 에폭은 전체 학습 데이터의 반복 횟수, 배치 크기는 한 번에 처리하는 이미지 수, 학습률은 한 단계에서 가중치를 조정하는 정도입니다. 마우스를 올리면 도움말을 볼 수 있습니다. 이번 수정은 표시와 안내만 바꾸며 실제 설정값·학습 동작·가중치는 그대로입니다.

## 여러 이미지 추론 · 이전/다음 보기

1. **추론** 화면에서 **이미지 선택 (여러 장 가능)** 또는 **이미지 폴더 선택**을 누릅니다.
2. 모델과 CPU/GPU를 선택하고 **전체 N장 추론 실행**을 누릅니다. 모델은 한 번 불러오고 한 장씩 순차 처리합니다.
3. 완료되면 **이전 / 다음**으로 이미지와 해당 Top-5 감성어를 함께 확인합니다. 현재 순서/전체 장수와 파일명도 표시합니다.
4. 5종 BERT 모델은 추론 전 이전·다음으로 이동하여 **각 이미지의 설명문을 따로 입력**하세요. 설명문이 빠진 이미지가 있으면 실행하지 않습니다. 이미지 전용 모델은 설명문이 필요 없습니다.
5. **추론 중단** 시 현재 이미지 처리 후 멈추며 완료된 결과를 보존합니다. 오류·미처리 이미지는 구분하여 표시합니다.

폴더 바로 아래 JPG·JPEG·PNG·WebP를 파일명 순으로 읽고, 하위 폴더와 바로가기는 제외합니다. 최대 1,000장, 개별 16MB, 전체 512MB까지 선택할 수 있습니다. 실행 중에는 입력·모델·설명문을 변경하지 못하지만 이미지는 넘겨볼 수 있습니다. 입력 사본과 결과는 `workspace/runs/<실행ID>`에 저장합니다. 화면 넘겨보기는 현재 실행에 대해 제공하며, 새 목록/모델을 선택하면 화면만 초기화하고 기존 기록은 남깁니다.

추론 입력에는 정답을 넣지 않습니다. 등록 정답이 있으면 완료 후 이미지별 일치 개수만 비교합니다. 이 값은 모델 전체 정확도와 다릅니다. 가중치·학습 계산은 변경하지 않았습니다. 화면 용어는 **학습 · 검증 · 평가(테스트)**이며 CSV/JSON의 `train/dev/eval`은 유지합니다.

## 추가학습한 가중치 저장과 불러오기

1. **가중치 보관함**에서 저장할 모델을 선택합니다.
2. **선택 가중치 다른 이름으로 저장…**을 눌러 로컬 폴더와 ZIP 파일 이름을 정합니다.
3. 새 분류부뿐 아니라 필요한 원본 백본·설정도 함께 저장됩니다. 수 GB 이상일 수 있습니다. 원본 가중치·현재 적용 모델은 바꾸지 않습니다.
4. 이 PC 또는 다른 PC의 프로그램에서 **저장한 가중치 ZIP 불러오기**를 누르면 무결성과 실제 로딩을 검사하고 보관함에 추가합니다. ZIP을 직접 풀거나 내부 폴더를 찾을 필요가 없습니다.
5. 추론과 다음 학습의 기준으로 쓰려면 불러온 모델을 선택하고 **선택 모델 적용**을 누릅니다. 불러오기만으로 자동 적용되지는 않습니다.

등록 이미지·정답 CSV·특징 캐시·전체 학습 로그는 백업 ZIP에 포함되지 않습니다. 모델 설정, 학습 이력/평가 수치, 학습 이미지 해시 등 모델의 재사용 적합성을 판단할 기록은 유지합니다. 기존 ZIP 교체는 확인 후 수행하며, 저장 실패 시 기존 ZIP을 보존합니다. ZIP 불러오기는 **이 프로그램의 다른 이름으로 저장 기능으로 만든 신뢰할 수 있는 파일**에만 사용하세요. 외부 원본 가중치는 기존 폴더 등록 기능을 사용합니다.

### 0.13 / 0.14 / 0.14.1 / 0.15에서 업데이트

프로그램을 종료한 뒤 기존 설치 폴더를 백업하고, 새 ZIP의 `PatternTraining` 안에 있는 프로그램 파일을 기존 폴더에 덮어씁니다. 기존 `workspace`와 가상환경 폴더는 지우지 마세요. 새 작은 ZIP에는 사용자 `workspace`가 없으므로 사용자 데이터·가중치를 덮어쓰지 않습니다. 기준 가중치는 변경하지 않았으며 기존 설치 환경을 그대로 사용할 수 있습니다. 처음 설치하는 PC는 아래 설치 순서를 따르세요.

이 ZIP은 통합 백업 ZIP과 다른 **작은 설치용 패키지**입니다. 모델 가중치 자체는 들어 있지 않습니다. 이미지 전용 DINO A/B·RBF와 5종 BERT 이미지·설명문 모델을 설치기가 분할 파일에서 복원합니다. 학습·평가·추론 코드는 통합본과 같습니다.

## 처음 설치

Python **3.11 64비트**를 설치하고, 이 ZIP을 서버/PC의 새 로컬 폴더에 풀어 주세요. NAS·네트워크 드라이브·바로가기 폴더는 지원하지 않습니다. 프로그램과 모델 및 설치 중 임시 공간으로 **최소 40GB 이상**의 여유 공간을 권장합니다. Python 패키지 다운로드에는 인터넷 연결이 필요합니다.

1. Windows: **install-windows.bat** 실행. Linux: **bash install-linux.sh --cpu** 또는 **--gpu** 실행.
2. 설치기가 가중치를 다운로드 → SHA-256 확인 → 합치기 → 개별 파일 검증 → `workspace/models` 자동 배치합니다.
3. Windows는 CPU(1) / NVIDIA GPU(2)를 선택합니다. 화면·학습·추론 패키지도 함께 설치합니다. GPU 드라이버 자체는 설치하지 않습니다.
4. 완료 후 **start-windows.bat** 또는 **bash start-linux.sh** 실행. Linux는 데스크톱 화면 연결이 필요합니다.

가중치를 따로 등록할 필요가 없습니다. 최초 기본 모델은 이미지 전용 모델입니다. 설명문을 함께 사용하는 경우 모델 선택란에서 5종 BERT 모델을 선택하세요. 프로그램과 가중치가 모두 설치된 뒤에는 모델 파일을 인터넷에서 다시 받지 않습니다.

## 가중치 다운로드

**weight_sources.json에 이 저장소의 desktop-v0.13 Release 주소를 연결했습니다.** 설치기가 가중치 6개를 자동으로 받습니다. 계정 비밀번호나 토큰을 프로그램에 입력할 필요가 없습니다. 네트워크나 배포 파일에 문제가 있으면 오류를 표시하고 멈추며, 불완전한 설치를 성공으로 표시하지 않습니다.

이미 분할 파일을 받았다면 `PatternTraining/weight_parts` 폴더를 만들고 `weights.zip.part001`부터 `weights.zip.part006`까지 **6개 모두** 넣으세요. 그다음 같은 `install-windows.bat`을 실행하면 다운로드 없이 자동으로 합쳐 설치합니다. ZIP 안의 `weights_parts.json`은 검증 정보가 추가되어 있으므로 다른 파일로 교체하지 마세요. 조각 하나만으로는 설치할 수 없습니다.

## 배포 담당자: 다운로드 위치를 변경할 때

기본 주소는 이미 설정되어 있습니다. 별도 배포 서버를 사용할 때만 `weight_sources.json`을 수정하세요. **실제 파일을 내려받는 HTTPS 주소**여야 하며 공유 폴더 URL이나 로그인/미리보기 HTML 주소는 사용할 수 없습니다. GitHub Release 등 동일 폴더의 직접 다운로드 주소이면:

```json
{
  "base_url": "https://YOUR-HOST/RELEASE-PATH",
  "urls": {}
}
```

`base_url` 뒤에 각 조각 파일명이 자동으로 붙습니다. 파일마다 주소가 다르면 `base_url`을 빈 문자열로 두고 `urls`에 6개를 모두 지정합니다.

```json
{
  "base_url": "",
  "urls": {
    "weights.zip.part001": "https://YOUR-HOST/FILE-1",
    "weights.zip.part002": "https://YOUR-HOST/FILE-2",
    "weights.zip.part003": "https://YOUR-HOST/FILE-3",
    "weights.zip.part004": "https://YOUR-HOST/FILE-4",
    "weights.zip.part005": "https://YOUR-HOST/FILE-5",
    "weights.zip.part006": "https://YOUR-HOST/FILE-6"
  }
}
```

예시 주소는 실제 주소가 아닙니다. 사용자에게 배포하기 전에 실제 URL로 설정하고 이 작은 ZIP을 다시 묶어 주세요. 사용자가 주소를 편집하거나 수동으로 합치게 할 필요는 없습니다. 검증용 `weights_parts.json`의 파일명·순서·크기·해시는 바꾸지 않습니다. 가중치를 새 버전으로 교체할 때는 검증 정보를 함께 갱신해야 합니다.

## 중단·재실행과 기존 자료 보호

- 설치가 끊기면 같은 설치 파일을 다시 실행하세요. 완전히 받은 검증된 조각은 재사용하고, 미완료 조각은 그 조각만 처음부터 다시 받습니다.
- 정상 설치 후 설치기가 받은 임시 조각과 합친 ZIP은 정리합니다. 사용자가 `weight_parts`에 넣은 파일은 삭제하지 않습니다. 이 수동 조각은 설치가 끝난 뒤 필요하면 사용자가 지울 수 있습니다.
- 이미 설치된 원본 모델은 해시 확인 후 재사용합니다. 기존 추가 학습 가중치·등록 데이터·학습 기록·적용 모델 설정은 덮어쓰지 않습니다. 보관함에서 삭제한 원본 모델도 자동 복원하지 않습니다.
- 기존 원본 모델의 내용이 달라졌거나 불완전하면 덮어쓰지 않고 멈춥니다. 이때는 원래 폴더를 보존하고 새 로컬 폴더에 설치하세요.
- 설치 중에는 프로그램 창을 닫아 주세요. 같은 저장 폴더에서 설치와 프로그램을 동시에 실행하지 않습니다.

## 학습·평가·추론

데이터(이미지와 정답 5개)를 등록 → 학습 → 평가 → 필요 시 새 가중치 적용 → 추론 순서입니다. 이미지 전용 모델은 이미지로 처리하고, 5종 BERT 모델은 이미지와 설명문을 함께 입력합니다. 추가 학습 시 기존 인코더는 고정하고 분류부/융합부를 이어서 학습합니다. 검증 데이터가 있으면 검증 F1@5가 가장 높은 에폭을 저장하며, 없으면 정해진 마지막 에폭을 저장합니다. 새 가중치는 자동 적용하지 않습니다.

학습에 사용한 표본을 다시 맞힌 값과 미사용 평가 성능은 다릅니다. 기존 이미지 모델의 배포 기록에는 평가 이미지의 학습 재사용이 포함되어 있으며 독립 테스트 성능이 아닙니다. 5종 BERT의 원기록 80%는 이미지+원설명문 조건입니다. 세부 모델 형식과 검증 범위는 `MODEL_FORMAT.md`, `VALIDATION.md`를 참고하세요.

Linux에서 자동 설치와 복원 검증을 수행합니다. Windows 배치 파일의 실행 연결은 검사하지만 실제 Windows PC에서의 실행 검증과는 구분합니다.
