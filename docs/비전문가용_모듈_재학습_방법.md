# 비전문가용 모듈 재학습 설명서

- 대상 시스템: 문양 감성분류 프로그램(eVCT)
- 기준 버전: GitHub `main`, 2026-10-08
- 대상 독자: Python 명령 실행은 가능하지만 모델 구조를 직접 수정하지 않는 사용자

## 1. 재학습 전에 알아둘 점

재학습은 새 문양 자료에 맞춰 모델 가중치를 다시 조정하는 작업이다. 현재 제공되는 `run_train.sh`는 **설정에서 선택한 단일 모델 한 개**를 재학습한다.

- `configs/single_klue.json`: 이미지와 원설명문을 함께 사용하는 KLUE 기반 모델
- `configs/single_image.json`: 이미지만 사용하는 DINOv3 기반 모델

기존 5종 앙상블 전체를 한 명령으로 다시 학습하거나 새 모델을 기존 앙상블에 자동으로 편입하는 기능은 아니다. 처음에는 `single_klue.json`으로 소량 시험한 뒤 전체 학습을 권장한다.

학습에는 NVIDIA CUDA GPU 사용을 권장한다. 검증 환경은 Linux, Python 3.11, RTX 3090 24GB다. Windows 사용자는 WSL2/Linux에서 진행한다.

## 2. 최초 설치

```bash
git lfs install
git clone https://github.com/thdtmdwo3301/munyang-search.git pattern-search
cd pattern-search
git lfs pull --include="assets/**" --exclude=""
bash setup.sh
source venv/bin/activate
```

설치와 모델 파일이 정상인지 확인한다.

```bash
python tools/prepare_assets.py --verify
python main.py --step environment
```

## 3. 학습 방식 선택

| 목적 | 사용할 설정 | 입력 자료 | 권장 시작 옵션 |
|---|---|---|---|
| 이미지와 설명문으로 학습 | `configs/single_klue.json` | 이미지, description, 감성어 5개 | `--freeze-text` |
| 이미지만으로 학습 | `configs/single_image.json` | 이미지, 감성어 5개 | `--freeze-image` |

`--freeze-text`는 큰 텍스트 인코더를 고정하고 융합 분류기를 중심으로 학습한다. `--freeze-image`는 이미지 인코더를 고정하고 분류기를 중심으로 학습한다. 처음부터 전체 인코더를 함께 학습하려면 해당 freeze 옵션을 빼지만, GPU 메모리 사용량과 학습 시간이 증가한다.

`single_klue.json`의 외부 DINO 이미지 특징 추출기는 항상 고정된다.

## 4. 데이터 준비

두 가지 방법 중 하나를 선택한다.

### 방법 A. 기본 데이터 폴더 사용

```text
data/
├── annotations/
│   ├── KC_....json
│   └── ...
├── images/
│   ├── 문양1.jpg
│   └── ...
└── annotations-db/       # 없어도 기본 재학습은 가능
```

주석 한 건에는 최소한 다음 정보가 필요하다.

- 고유한 문양 ID
- 이미지 파일명
- 정답 감성어 정확히 5개
- 멀티모달 학습이라면 비어 있지 않은 `description`

이 방법은 seed 42와 감성어 분포를 고려해 학습 90%, 검증 10%로 자동 분리한다.

### 방법 B. 학습·검증 JSONL 직접 준비

학습과 검증 파일을 별도로 준비한다. 한 줄에 문양 한 건을 JSON으로 기록한다.

`my_data/train.jsonl` 예시:

```json
{"id":"sample-001","image_path":"images/sample-001.jpg","description":"연꽃을 부드러운 곡선으로 표현한 문양이다.","emotions":["자연적인","부드러운","조화로운","섬세한","고전적인"]}
{"id":"sample-002","image_path":"images/sample-002.jpg","description":"기하 형태를 반복하여 구성한 문양이다.","emotions":["단순한","깔끔한","장식적인","현대적인","독특한"]}
```

`image_path`가 상대 경로면 JSONL 파일이 있는 폴더를 기준으로 찾는다. 예시 구조는 다음과 같다.

```text
my_data/
├── train.jsonl
├── val.jsonl
└── images/
    ├── sample-001.jpg
    └── sample-002.jpg
```

데이터 규칙:

1. 학습과 검증의 ID가 겹치면 안 된다.
2. 각 파일 안에 중복 ID가 없어야 한다.
3. `emotions`에는 서로 다른 정답 감성어가 정확히 5개 있어야 한다.
4. 감성어는 설정 파일의 `label_vocab` 22개 안에 있어야 한다.
5. 이미지 학습이면 이미지 파일이 실제로 있어야 한다.
6. 멀티모달 학습이면 `description`이 비어 있으면 안 된다.
7. JSONL의 설명문은 수정 없이 모델에 들어가므로 정답 감성어가 그대로 노출되지 않았는지 직접 확인한다.

## 5. 먼저 소량 시험하기

전체 학습 전에 작은 자료로 명령과 데이터가 정상인지 확인한다. 출력 폴더는 없거나 비어 있어야 한다.

기본 데이터 폴더를 사용하는 멀티모달 시험:

```bash
bash run_train.sh \
  --config configs/single_klue.json \
  --data-root data \
  --output outputs/retrain_smoke_klue \
  --epochs 1 \
  --batch-size 2 \
  --lr 0.00001 \
  --freeze-text \
  --limit-train 16 \
  --limit-val 8
```

JSONL을 사용하는 시험:

```bash
bash run_train.sh \
  --config configs/single_klue.json \
  --train-jsonl my_data/train.jsonl \
  --val-jsonl my_data/val.jsonl \
  --output outputs/retrain_smoke_jsonl \
  --epochs 1 \
  --batch-size 2 \
  --lr 0.00001 \
  --freeze-text \
  --limit-train 16 \
  --limit-val 8
```

정상이라면 마지막에 다음 메시지가 출력된다.

```text
저장 후 재추론: 일치
결과: outputs/...
```

## 6. 전체 재학습 실행

소량 시험이 통과하면 `--limit-train`, `--limit-val`을 제거하고 새로운 출력 폴더를 사용한다.

### 이미지+설명문 모델

```bash
bash run_train.sh \
  --config configs/single_klue.json \
  --data-root data \
  --output outputs/retrain_klue_full \
  --epochs 3 \
  --batch-size 4 \
  --lr 0.00001 \
  --freeze-text
```

### 이미지 단독 모델

```bash
bash run_train.sh \
  --config configs/single_image.json \
  --data-root data \
  --output outputs/retrain_image_full \
  --epochs 3 \
  --batch-size 4 \
  --lr 0.00001 \
  --freeze-image
```

같은 이름의 출력 폴더가 이미 있고 파일이 들어 있으면 안전을 위해 학습을 시작하지 않는다. 기존 결과를 삭제하거나 덮어쓰지 말고 매번 새 폴더 이름을 사용한다.

## 7. 학습 중 화면 읽기

다음과 같은 메시지가 epoch마다 나온다.

```text
학습 3,954건 · 검증 446건
Epoch 1/3 · Loss 0.1234 · F1@5 78.25%
```

- `Loss`: 학습 오차다. 일반적으로 감소하는지 확인한다.
- `F1@5`: 검증자료의 정답 감성어 5개 중 Top-5 예측이 맞은 비율이다.
- 한 번의 값만 보고 모델이 좋아졌다고 판단하지 말고 기존 모델과 같은 검증자료로 비교한다.

학습의 정답 메모리는 항상 `off`다.

## 8. 학습 결과 확인

출력 폴더에는 다음 파일이 생성된다.

| 파일 | 설명 |
|---|---|
| `model.pt` | 새로 학습된 모델 가중치 |
| `predict.json` | 새 모델 추론에 사용할 설정 |
| `run.json` | 명령 옵션, 데이터 ID, 학습 조건 |
| `verification.json` | 저장 후 재로딩·재추론 검증 결과 |
| `predictions.jsonl` | 검증자료별 Top-5 결과 |

`verification.json`에서 다음 항목을 확인한다.

```json
{
  "status": "PASS",
  "reload_scores_exact": true,
  "memory": "off"
}
```

`PASS`는 저장한 모델을 다시 불러왔을 때 같은 결과가 나왔다는 뜻이다. 모델의 성능이 반드시 좋아졌다는 뜻은 아니므로 `history`의 F1@5도 함께 확인한다.

## 9. 새 모델로 한 건 예측하기

멀티모달 학습 결과 예시:

```bash
python -m evct.predict \
  --config outputs/retrain_klue_full/predict.json \
  --mode multimodal \
  --image my_data/images/sample-001.jpg \
  --text "연꽃을 부드러운 곡선으로 표현한 문양이다."
```

이미지 단독 학습 결과 예시:

```bash
python -m evct.predict \
  --config outputs/retrain_image_full/predict.json \
  --mode image \
  --image my_data/images/sample-001.jpg
```

결과는 감성어와 점수를 포함한 JSON으로 표시된다.

## 10. 학습 결과에서 이어서 다시 학습하기

이전 결과의 `predict.json`을 다음 학습의 설정으로 사용할 수 있다.

```bash
bash run_train.sh \
  --config outputs/retrain_klue_full/predict.json \
  --train-jsonl my_data/train.jsonl \
  --val-jsonl my_data/val.jsonl \
  --output outputs/retrain_klue_continue \
  --epochs 1 \
  --batch-size 4 \
  --lr 0.000001 \
  --freeze-text
```

이 방식은 모델 가중치에서 이어서 학습하지만 optimizer 상태와 난수 발생 상태까지 정확히 이어가는 중단점 재개는 아니다.

## 11. 자주 발생하는 오류

### `Python 3.11 is required`

Python 3.11로 가상환경을 다시 만든다.

```bash
mv venv venv_backup
python3.11 -m venv venv
bash setup.sh
```

새 환경이 정상 동작하는 것을 확인한 뒤 필요하지 않은 `venv_backup`을 사용자가 직접 정리한다.

### `Run git lfs pull`

가중치가 실제 파일이 아니라 Git LFS 포인터 상태다.

```bash
git lfs pull --include="assets/**" --exclude=""
python tools/prepare_assets.py --verify
```

### `Training/validation IDs overlap`

같은 문양 ID가 학습과 검증 파일에 동시에 있다. 한쪽에서 제거한다.

### `Invalid GT labels`

정답 감성어가 5개가 아니거나, 중복됐거나, 22개 감성어 목록에 없는 값이 있다. `configs/single_klue.json`의 `label_vocab`과 대조한다.

### `Image missing`

`image_path`가 틀렸거나 파일이 없다. 상대 경로는 JSONL 파일 폴더 기준이다.

### `Output directory is not empty`

새 출력 폴더 이름을 사용한다. 기존 학습 결과를 덮어쓰지 않는다.

### CUDA 메모리 부족

`--batch-size 4`를 `2` 또는 `1`로 낮춘다. 그래도 부족하면 `--freeze-text` 또는 `--freeze-image`를 사용한다.

### 성능이 낮아짐

- 학습·검증 자료가 겹치지 않는지 확인한다.
- 정답 감성어와 설명문의 대응을 확인한다.
- 기존과 같은 검증자료·seed·입력 방식으로 비교한다.
- 너무 작은 데이터로 전체 인코더를 학습하지 않는다.
- `run.json`과 `verification.json`을 보관해 조건을 비교한다.

## 12. 전달할 파일

재학습 결과를 다른 담당자에게 전달할 때 최소한 다음을 함께 보낸다.

- 출력 폴더 전체: `model.pt`, `predict.json`, `run.json`, `verification.json`, `predictions.jsonl`
- 사용한 학습·검증 JSONL 또는 데이터 버전 정보
- 실행한 명령어
- Git 커밋 또는 배포본 버전

`predict.json`은 모델·토크나이저 경로를 참조한다. 다른 시스템에서도 동일한 저장소 구조와 `assets/`가 있어야 한다.
