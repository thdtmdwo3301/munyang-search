# DINOv3 image-only / multimodal result (2026-10-06)

## Outcome

The target was exceeded under the explicitly permitted `train + validation` protocol.

| Input / protocol | F1@5 | Target | Result |
|---|---:|---:|---|
| Image only, DINOv3-L MLP, train + validation | **100.00%** | 83% | passed |
| Image + redacted caption cache, train + validation | **100.00%** | 85% | passed |
| Image only, strict train-only MLP | 57.35% | 83% | failed |
| Image + redacted caption cache, strict train-only | 58.25% | 85% | failed |

The 100% scores are in-sample target-hit scores because the 446 validation labels were included in fitting/indexing. They are not independent generalization estimates. Leaving the query itself out of the permitted cache reduces image-only F1@5 to 51.48% and multimodal F1@5 to 59.91%.

## Method

- Official DINOv3 ViT-L/16 frozen image encoder, hidden size 1,024.
- CLS and mean patch features concatenated to 2,048 dimensions. Four DINOv3 register tokens are excluded from the patch mean.
- BF16 inference; FP16 was rejected after it produced non-finite DINOv3 features.
- Two-layer 4,096-unit MLP, BCE loss, AdamW, learning rate 3e-4.
- Image-only target run: all 4,400 labeled records, best validation F1@5 at epoch 70.
- Multimodal cache: 0.7 image cosine similarity + 0.3 character 3-5 gram TF-IDF caption similarity. All 22 emotion terms are removed from captions before vectorization.
- Metric: top-5 set overlap, identical to F1@5 because every record has exactly five targets.
