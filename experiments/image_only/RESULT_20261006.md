# DINOv3 strict image-only / multimodal result (2026-10-06)

## Outcome

Validation is excluded from training. Results that fitted or indexed validation
labels are retired and are not counted toward either target.

| Input / protocol | F1@5 | Target | Result |
|---|---:|---:|---|
| Image only, two strict DINOv3 probability blend | **60.00%** | 83% | failed |
| Image only, external pseudo-label DINOv3-L (Blackwell) | 59.28% | 83% | failed |
| Image only, DINOv3-L last-8-block fine-tuning | 59.06% | 83% | failed |
| Image only, Qwen3-VL vision tower | 57.89% | 83% | failed |
| Image only, DINOv3-L frozen feature MLP | 57.35% | 83% | failed |
| Image + redacted caption cache | 58.25% | 85% | failed |
| Image + caption, Qwen3-VL last-2-block fine-tuning | 73.14% | 85% | failed |
| Existing five-model multimodal ensemble | 80.00% | 85% | failed |

The 60.00% image-only result blends the original end-to-end DINOv3 run and the
independent Blackwell pseudo-label run; its scalar weight was selected on the
validation split in the same model-selection role as best-epoch selection. The
individual Blackwell model reached 59.28%. The existing 80.00% multimodal
ensemble is the strongest verified strict result available in the project
artifacts. Neither requested threshold has been reached.

## Method

- Official DINOv3 ViT-L/16 image encoder, hidden size 1,024.
- CLS and mean patch features concatenated to 2,048 dimensions. Four DINOv3 register tokens are excluded from the patch mean.
- BF16 inference; FP16 was rejected after it produced non-finite DINOv3 features.
- End-to-end strict run: last eight transformer blocks unfrozen, BCE loss,
  AdamW, BF16, 40 epochs; best validation F1@5 at epoch 5.
- External visual pretraining: 445,322 images with Qwen3-VL adjective pseudo
  labels. Exact SHA-256 duplicate audit found zero overlaps with the 446
  validation images. H200 and Blackwell variants reached 59.01% and 59.28%.
- Qwen3-VL image-only: vision tower last four blocks, 57.89%.
- Qwen3-VL multimodal: frozen 4B backbone head training followed by last-two
  text-block fine-tuning, 73.14%. Blending it with the existing 80% ensemble
  did not improve the existing ensemble.
- Frozen-feature baseline: two-layer 4,096-unit MLP, BCE loss, AdamW.
- Multimodal cache: 0.7 image cosine similarity + 0.3 character 3-5 gram TF-IDF caption similarity. All 22 emotion terms are removed from captions before vectorization.
- Metric: top-5 set overlap, identical to F1@5 because every record has exactly five targets.
